# 桌面端：管家

管家是 MNS 里的一个独立人格：它读同一份账本，可以聊账面、聊市场、给倾向性
看法——观点是它的，标明「我的看法」；决定是你的。它不接券商、下不了单，
账本数字只念本地事实，不编。

> 双人格边界：主窗口的「助手」页仍是严格的工具型护栏（不给买卖点、不预测）。
> 管家是自主人格，两套口径是设计如此，见「它不会做什么」一节。

## 什么时候会主动找你

管家先巡检，再判断要不要开口——**有唤醒不等于有通知**。下面三类由头
成立时，说一次：

| 由头 | 例子 |
|---|---|
| 自设任务到点 | 你让它在下个决策日提醒核对计划 |
| 有可执行的下一步 | 决策日偏离超出带宽，或新钱到账且计划有单 |
| 承诺到期 | 你说过「等发工资补仓」，到点提醒 |

这三类都没有的时候，管家还可以自己找话头：把账本、记忆和最近的对话交给
agent，由它判断此刻有没有值得说的一句话（`agent-init`）。它只有一句话、
走通知口径，而且同样先过频控和静音。拿不准就不说——主动开口没有模板兜底，
沉默是正确结果。

行为日志（打开买入弹层、护栏命中、反复查看同一页）仍然记录，也会出现在
会话回答里，但**不单独构成开口理由**：只看「你看了 5 次」就提醒，会变成
催促；而项目没有指数级行情，无法诚实判断「市场动了多少」。

此外还有频控，默认每天最多三次、每周（滚动 7 天）最多十次、夜间 22–08 点
静音、同一件事 3 天内不重复。这些数值在设置页「管家 → 主动开口频控」或
`config.toml` 的 `[butler]` 节里改，改完立即生效，不用重启（静音起止小时相同
表示不静音）。绝大多数巡检的结论是「没什么值得说」，这是设计目标，不是故障。

## 在哪里看到它

- 系统通知：管家开口时弹一条横幅，点开直接进管家会话；
- 托盘菜单：有提示时菜单第一行就是那句话，点开进入会话；
- 菜单「操作 → 管家」或设置页「打开管家」；
- 会话和未读数只存在本机，关掉窗口不会丢。

在会话输入框里按 Enter 直接发送，Shift+Enter 换行。

## 关掉窗口之后

管家的判定跑在独立的守护进程 `mns-butlerd` 里（随 MNS 启动，退出主界面后仍
在）。所以：

- 关掉主窗口只是隐藏界面，到点提醒、账本事件照常；
- 它不按固定间隔轮询：算出「下一件事在哪一刻」（定时巡检、你的任务到点、
  承诺到期），睡到那一刻才醒；记账、加任务、改记忆都会直接叫醒它；
- 没有确定性由头时，它还会按需起一次外部 agent，看看有没有值得主动说的一句
  话；拿不到合规的回答就沉默，不阻塞下一次巡检；
- 用命令行记账（`mns cash deposit`、`mns buy` 等）也一样立刻生效；
- 它要开口时会写进待投递队列，下次打开界面时补进会话，不会丢；
- 托盘菜单「停止管家进程」可以彻底停掉它，之后判定回到主界面进程里。

这些时间都算在进程内，没有交给系统计划任务（launchd / cron / 计划任务）：
不需要额外的登录项或后台权限，也不会因为系统调度器的节流而晚几分钟。

系统通知只能由主界面进程送达（macOS 的限制），所以守护进程负责「判断该不该
说」，横幅由主界面发出；主界面完全退出时，话会留在会话里等你回来。

Windows 上守护进程同样常驻（走命名管道与主界面握手），但目前没有系统横幅：
开口会直接进会话，并在托盘提示里等你点开。

## 能问什么

管家有两条路：能交给 agent 的交给它，交不出去就回到本地模板。模板是确定性
的——同一份账本，问几次都是同一个数；断网、关掉 agent 都还能问。

| 你问 | 它答 |
|---|---|
| 偏离多少 / 配置比例 | 各腿现状与目标、哪条腿超出带宽 |
| 分析持仓 / 总资产 | 总资产、持仓与现金、偏离最大的腿 |
| 本月计划 / 要买多少 | 逐腿金额，以及计划被拦下的原因 |
| 哪天决策 / 今天要注意什么 | 决策日、当天入金、到期承诺、数据是否当天 |
| 明天怎么看 / 要不要动 | 管家自己的看法与理由，标明是观点；说不准就直说 |
| 你记得什么 | 常驻记忆里的条目原文 |
| 你能做什么 / 你是谁 | 能力与身份 |

问法不必精确。观点类问题（涨跌、买卖、市场）会正常交给 agent 回答；本地
兜底只在 agent 不在时接管，那时它只答有把握的部分：

- 外面今天有什么新闻——本地没有源，直说不知道，不编；
- 涨跌预测——「说不准，不装确定」，再把有把握的账面递上来；
- 追问可以接着上一句（「那 A 股呢」），换话题则要重新说清问什么。

## 说话方式

管家像人在聊天，不像交报告：

- 先给结论，再给一两句理由；默认两到四个短段落，大约 300 字以内；
- 想听长一点，直接说「展开」「细说」「详细讲讲」，它才会展开；
- 一次只点两三个关键数字，不把每条腿、每个指标都念一遍；
- 支持简单的 markdown：关键数字会加粗，短列表照常显示；
- 不写「我先查一下」这类过程旁白，也不贴 `action:` 之类的内部字段——即使
  模型写了（包括升级前的旧记录），也会在显示前被清掉；
- 观点会标明是它的看法，数字仍是账本事实，下单它做不了。

断网或 agent 不可用时，回答退回本地模板：更短，只答有把握的部分。

## 记住什么、不记住什么

- 只记你明确说过的偏好、承诺与关键结论，且最多每次三条；
- 在会话里说「记住：周五补美股」，或带日期「记住 2026-11-20 截止 补房贷」，
  会直接写入记忆；说「忘掉补美股」则移入归档；
- 事实上限 100 条、摘要上限 20 条，满了先合并归档，不静默删除；
- 「忘掉这件事」会把命中的事实移入归档，可以查，不是假装没发生过；
- 任务默认最多 10 条活跃，超 24 小时未处理自动作废。

## 关掉主动开口

设置页「管家 → 主动开口」可以随时停止提示；旁边的「主动开口频控」可以改
每天/每周上限、去重天数与静音时段（也等价于编辑 `config.toml` 的
`[butler]` 节）。关闭主动开口后：

- 唤醒与每周自整理照常（记忆仍会被整理，任务仍会复盘）；
- 管家窗口仍然可以问、可以答；
- 账本、报告、助手存档都不受影响。

命令行等价操作：`mns-butler mute` / `mns-butler unmute`，`mns-butler status`
可以看到当前开关、生效中的频控与开口记录。

## 它不会做什么

- 不编账本数字：回答里的账面数字只来自本地事实或只读命令输出；
- 不谎称已经下单或改了账：它没有券商通道，动账的只有你本人；
- 不改策略参数、不动助手页的护栏（那是 MNS 助手人格的约束，不是管家的）；
- 管家窗口不受理工具授权：agent 申请写文件一类权限会被直接拒绝，要授权请
  在主窗口的助手页操作；
- 不读写 AI 助手的历史会话（只共享同一份本地账本）；
- 账本、记忆、开口判定与通知都在本机处理。

主动开口（系统通知 banner）比会话更节制：通知文案仍走最严口径，长度 ≤60 字、
不含买卖点类话术。会话里可以聊观点，通知里只报事实——弹窗是打扰通道，克制
是它的礼貌。

## 回答是谁生成的

管家自己不推理：它把账本摘要和你的问题交给外部 ACP agent（默认
`opencode acp`，在设置页「AI 助手」里指定 CLI 与模型）。provider、模型与
密钥都在 agent 自己的配置里，MNS 不保存，也不直连任何模型服务。

这让回答能顺着你的问法走，代价要说清楚：

- 每次提问要起一次 agent 会话，比模板慢；
- agent 带工具权限，会自己去跑 `mns portfolio`、`mns cash` 这类只读命令。
  它拿到的数字可能比摘要更细，所以**不再逐项比对数字白名单**——数字准确性
  靠提示词约束和你自己核对，不像模板那样由代码保证；
- 预测与观点类问题正常发出去，由 agent 以管家人格回答；记忆类命令
  （「记住…」「忘掉…」「你记得什么」）在本地处理，不启 agent；
- agent 没装、没登录、超时，或回答超长不像话、谎称已经替你下单，这一条就
  退回本地模板，并在消息下方写明原因。所以断网、关掉 agent 之后，管家仍然
  能答（只是只剩有把握的账面部分）。

每次提问发出去的是：你的这句话、一份账本摘要（数据日期、总资产与现金、逐腿
偏离与目标、计划金额、今日入金、到期承诺），以及同一个会话里的前几轮问答。
交易流水明细、报告全文、助手会话都不发。

管家的每次开口都能在 `~/.mns/agent/butler/` 里查到：唤醒状态、开口记录、
记忆、任务与出站通知队列。
