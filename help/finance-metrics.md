# 收益与风险指标

买基金、买理财时App上那一排指标，分别是什么意思、什么时候会骗人。

## 收益类

| 指标 | 含义 | 看点 |
|---|---|---|
| 累计收益率 | 区间总回报 | 最直观，受起止时间影响大 |
| 年化收益率 | 折算成一年的复合收益 | 跨周期对比的标准口径 |
| 超额收益 | 相对业绩基准多赚的部分 | 判断是真本事还是大盘涨 |
| IRR | 考虑时间价值的真实年化 | 保险类唯一可信指标，须用合同现金价值表自算 |

## 风险类

| 指标 | 含义 | 看点 |
|---|---|---|
| 波动率 | 年化标准差，收益上下起伏 | 波动越大，持有过程越颠簸 |
| 最大回撤 | 从最高点到最低点的最大跌幅 | **最影响持有体验的指标** |
| 下行波动率 | 只统计亏损方向的波动 | 比标准差更贴近「怕亏」心理 |
| Beta | 相对基准的弹性，>1 更激进 | 牛市放大器，熊市也放大 |
| 跟踪误差 | 偏离基准的波动程度 | 指数基金越小越好 |
| 久期 | 债券价格对利率的敏感度 | 久期越长，利率上行跌得越狠 |

## 风险调整后收益：横向比较基金的核心

区别只在**分母用哪种风险**：

| 指标 | 公式 | 适用场景 |
|---|---|---|
| 夏普比率 | (收益−无风险利率) ÷ 总波动率 | 最通用；对「平时小赚、偶尔暴跌」会给出虚高分数 |
| 卡玛比率 | 年化收益 ÷ 最大回撤 | 专治「夏普好看但拿不住」 |
| 索提诺比率 | (收益−目标收益) ÷ 下行波动率 | 只惩罚下跌，不惩罚上涨 |
| 特雷诺比率 | (收益−无风险利率) ÷ Beta | 只考虑系统性风险，适合高度分散组合 |
| 信息比率 | 超额收益 ÷ 跟踪误差 | 衡量超额收益稳定性，指数增强必看 |
| 詹森 Alpha | 实际收益 − CAPM 理论收益 | 剔除市场涨跌后的纯选股能力 |

**参考阈值**：夏普 >1 算优秀，>2 极少见；卡玛 >1（年化收益超过最大回撤）已相当不错。

## 持有体验与运作类

| 指标 | 含义 | 为什么重要 |
|---|---|---|
| 月度／季度胜率 | 跑赢基准或正收益的月份占比 | 高胜率更容易被长期持有 |
| 回撤修复天数 | 从回撤底部爬回前高的时间 | 比回撤幅度更折磨人 |
| 规模 | 基金资产总规模 | 太小有清盘风险，太大拖累灵活性 |
| 换手率 | 一年内买卖股票的周转倍数 | 高换手＝交易成本高、风格漂移 |
| 持仓集中度 | 前十大占比、行业集中度 | 决定波动来源 |
| 费率 | 管理费＋托管费＋销售服务费 | 长期复利下差异惊人 |
| 基金经理任职年限 | 现任经理管理该产品的年数 | 指标再好，经理换了也白搭 |

## 费率改革（2026 年 1 月全部落地）

| 费用项 | 当前上限 | 备注 |
|---|---|---|
| 主动权益管理费／托管费 | 1.2% / 0.2% | 由 1.5% / 0.25% 下调 |
| 被动股票型交易佣金 | 0.26‰ | 其他类型不超过 0.52‰ |
| 认申购费 | 主动偏股 0.8%／其他混合 0.5%／指数与债券 0.3% | 销售环节 |
| 销售服务费 | 股混 0.4%／指数与债券 0.2%／货基 0.15%（年） | 持有超 1 年的非货基不再计提 |
| 主流宽基 ETF 综合费率 | 0.15% + 0.05% = 0.20%／年 | 全市场超 370 只已降至该水平 |

费率改革后，同类指数基金的费率差已从 0.5% 缩到 0.1% 以内——选品不必再为省几个基点牺牲流动性，但**跨品类**（QDII 普遍 0.6%~1.2%）的差异仍值得算。

## 指标使用边界

> [!WARNING]
> - **夏普、卡玛只在同类产品间有意义**，跨风险层级比较无效。
> - 看历史年化前先确认它**跨过了哪一轮牛熊**，以及是价格指数还是全收益指数——红利低波近 5 年价格年化约 5.5%、全收益约 11.5%，差的就是股息。
> - **回撤决定能不能拿住，波动只决定过程颠不颠**，二者不可混用。
