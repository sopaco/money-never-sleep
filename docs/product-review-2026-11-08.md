# MNS 产品评审：能否真实服务"稳健档 · 回撤敏感 · INTJ"投资者

> 评审日期：2026-11-08 · 评审人：product · 基于 HEAD `058d0d8`（strategy optimized）
> 用户档案：steady 档（core_blend 0.4），初始资金约 ¥10000（2026-07-16 入场），当前总资产 ¥9741.50
> 用户目标原文："不追求赚的最多，但求不踩坑、回撤小、符合策略预期，适合 INTJ 类型的投资人"

---

## 一、总体结论

**策略内核：能。产品闭环：尚差一步。**

MNS 的逆情绪策略框架（恐贪指数 → 目标仓位 → 偏离带）在回测证据、反噪声机制设计、诚实披露三个维度上，确实是为"回撤敏感 + 规则驱动"的投资者量身打造的，与 INTJ 的决策风格高度匹配。但当前产品存在一个关键断裂：**它给了用户一套预期（回测：MaxDD ~9%），却没有给用户任何验证自己实际体验是否符合预期的工具**。用户当前实际收益 -2.6%（美股腿 -11%~-12%），正处于策略"设计内"的接飞刀期，但产品无法让用户确认"这是策略预期中的正常状态"还是"策略失效"——而这恰恰是该用户目标里"符合策略预期"的核心诉求。

另有一个**语义级错位**需要优先修复：用户为"回撤小"选择"稳健"档，但回测数据显示**"稳健"档不是回撤最小的配置**（详见第三节）。

### 3.2 核心发现

**发现 1："稳健"档不是回撤最小的选择。**
无档位（core_blend=0）的曲线在极度贪婪时只保留 28% 风险仓位，而"稳健"档把地板抬到 57%（`目标 = core_blend×100 + (1-core_blend)×曲线`，向满仓收缩）。结果：无档位 MaxDD 6.96% < 稳健档 8.92%，Calmar 1.35 > 1.20。"稳健"档的真实语义是**"减少择时摆动 + 提高常驻仓位"**（行为上更稳：3.4 笔/年 vs 6.1 笔/年），不是"更小的回撤"。一个为"回撤小"而来的用户会因为名字选错配置，多承担 ~2pp 回撤。且档位对比表**不显示 core_blend=0 基准行**，用户无从发现这一点。

**发现 2：回测证明更好的信号（趋势锚）在实盘中不可达。**
趋势锚 Calmar 1.43 vs 情绪锚 1.20，holdout（2025-07~2026-07）+12.46% vs +8.75%。但趋势锚只存在于回测引擎；实盘信号只接了 CNN 情绪。`price_history` 表在当前代码中是**孤儿表**（无任何读写路径，数据停留在 2026-09-02）——"趋势锚需要 12 个月本地价格历史"的前提条件永远无法满足。

**发现 3：用户的实际行为模式（小额多频加仓）对应回测里回撤最小的注资方式（月频定投 5.44%），但产品没有把这个事实告诉用户。** 注资频率对比只在 `backtest run` 的长输出里，日报无从得知。

> **【2026-11-08 整改修正】此条结论不成立，已撤回。**
> 月频定投 MaxDD 5.44% / Calmar 1.90 的回撤优势来自**外部新增资金持续摊薄成本**——回测设定初始 ¥100,000 + 每年 ¥50,000、累计投入 ¥550,000。用户实盘是约 ¥10,000 期初、`cashflow.monthly = 0.0`、**无后续外部注资**；「小额多频加仓」是用账户内既有现金做内部再平衡，数学上是两件事。
> 在没有外部现金流入时，连续恐慌加仓会迅速耗尽现金缓冲，而现金缓冲正是回测里平均 25% 仓位得以维持的前提。当前报告显示目标 88.8% / 当前 70.0%、建议买入 ¥1,788.72，而现金仅 ¥2,919.40——继续加仓会直接消耗这层保护。
> 因此 S2 的 onboarding 建议必须改为**条件式**：仅当账户有稳定外部现金流入时才成立。修正后的验证以 `mns backtest mirror` 的账户镜像为准（严格执行 vs 实际执行，均无后续注资）。

**发现 4（诚实性）：压力测试覆盖不足是已知且已披露的**——FGI 数据始于 2016，无 2000-02/2008 型多年熊市，"熊市回撤保护"这一对该用户最重要的卖点未经检验。这一点 `backtest validate` 披露得很到位，但**日报层面没有任何提示**。

## 四、缺陷清单（按对该用户目标的伤害排序）

### P0-1 档位语义错位（伤害：用户目标直接受损）
- "稳健"名字暗示更低风险，实际抬高风险地板（28%→57%）。
- 日报文案"档位只收窄择时摆幅，不改你的曲线锚点"进一步强化误读——有效中性锚点实际从 62% 移到 77%，"不改"指的是 config 里的曲线参数值。
- 档位对比缺 core_blend=0 基准行，错位无从被发现。

### P0-2 无法验证"符合策略预期"（伤害：用户核心诉求无工具支撑）
- 无组合级 XIRR / 实际最大回撤 / 总资产曲线：`portfolio` 只有单标的收益。
- `cash set` 直接覆盖余额（cash 表单行无历史），资金注入不可追溯 → 组合 XIRR 在数学上不可算。
- 无"策略模拟 vs 实际执行"对照：交易流水与报告建议未关联，用户无法知道"如果我严格照做，现在应该是什么样"。
- 用户的实盘体验（-2.6%、美股 -12%）处于策略设计内状态，但产品没有任何仪表盘能说明这一点。

### P1-3 更优信号不可达 + 诚实披露从日报消失
- 趋势锚锁死在回测里；`price_history` 孤儿表无积累路径。
- 【信号口径】章节（旧版 report.rs:281-291，含"情绪信号在加入趋势锚后贡献接近零"）已在重构中被删除，当前日报无任何信号局限提示。诚实性只留在用户很少运行的 `backtest validate` 输出里。

### P1-4 数据单点故障（伤害：最需要时不可用）
- `cmd_report_inner` 中 `fetch_fear_greed_data(url).await?` —— CNN 反爬 418 是文档已知的常态风险，一旦失败**整个报告直接失败**。
- 本地有 84 天快照，却无降级路径（价格已有 `price_age_days` 陈旧警告模式，情绪应复用同一模式）。

### P1-5 档位切换冲击（伤害：违背产品自身哲学）
- 切换档位 → 目标仓位瞬间重锚 → 立即产生大额调仓建议。用户今日两次切换，两次看到不同的大额买入。
- 无预警（"本次切换将立即产生约 ¥X 调仓"）、无过渡机制。

### P2-6 存档非 append-only（伤害：审计性承诺落空）
- `save_report` 用 `fs::write` 覆盖 `YYYY-MM-DD.txt`：同日重复运行会销毁更早快照。用户今日的 steady 档报告已被 balanced 档运行覆盖，"先留档再决策"在同日重跑场景下失效。

### P2-7 账本无撤销（伤害：已在真实用户身上发生）
- 首日（07-16）即出现手工对冲错账（卖出 ¥2202.41 修正超记 + 卖出 ¥1.56 残差）。误记无 `transactions` 编辑/删除命令，修正交易会污染月度操作统计（"本月已操作 N 笔"）与费用估算。

### P2-8 期待管理缺失（伤害：接飞刀期的心理体验）
- 恐慌区间持续加仓是设计行为，但日报不提供历史对照（"恐慌区间历史上平均持续 X 个月""2018/2022 同类期策略回撤 Y%"），用户只能裸奔承受。

### P3 细节问题
- TL;DR"买入 ¥1300"（百位取整）与"净买入 ¥1352.31"（精确值）并存，INTJ 用户会视为数据不一致。
- `backtest run` 的 `--config` 与 `--compare` 短旗冲突（都注册了 `-c`，后者实际不可用）。
- `mns config profile` 只有 steady/balanced/aggressive，无"无档位（core_blend=0）"预设，想看基准必须手改 TOML。
- `min_trade_amount` 按腿检查，腿内单标的金额（如 ¥350）可远低于它，与"低于最小交易额"的 hold 话术语义不一致（基金平台实际无碍，纯语义问题）。

## 六、回答使命问题

**"这个 mns 项目是否能真实帮助到这类投资者？"**

- **策略与机制设计：是。** 反噪声机制链（7 天平滑 + 3 天区间确认 + 6pp 带宽 + 最短持有期 + 费用模型）对"回撤敏感 + 规则驱动"的用户是真实有效的；压力年份（2018/2022）拆解显示策略确实把 -15% 的年份变成 -8%，把 13% 回撤压到 8%。
- **档位选择：评审时是反向的，现已修复。** 该用户要"回撤小"，正确答案是 core_blend=0（无档位），而不是"稳健"档。原产品用名字把最安全意识强的用户引向了回撤更大的配置——本 mission 已通过 W2（基准行可见）+ W3（语义如实披露 + `none` 预设）修复：现在 `mns config profile none` 一键可达，报告明示"档位抬高常驻仓位并收窄择时摆幅，这不降低风险"。
- **验证闭环：评审时缺失，现已补齐。** 用户目标三要素（不踩坑/回撤小/符合预期）中"符合预期"原本完全无工具支撑。本 mission 交付 C1-C4 后：`mns performance` 输出组合 XIRR、实际最大回撤、与策略回测预期的现场对照——用户第一次能量化回答"我是否在策略预期内"。现金流台账与每日快照已开始积累（用户真实库已于 2026-11-08 启用）。
- **限制条件（已常态化披露）**：回测区间 2016-2025 无多年期熊市，"熊市回撤保护"未经检验；CNN 情绪对 A股/黄金腿解释力有限。这两点已从"藏在 validate 输出里"变为每日报告的【信号与局限】固定尾注（W1），且 CNN 断连时降级到本地快照而非整报告失败（W4）。
