## GPUI Kit 桌面端技术方案（只读设计）

- 用户计划新增基于 GPUI Kit 的 macOS/Windows 桌面程序，要求托盘、窗口、易用操作和面向普通投资者的数据可视化；指定参考项目内 `.agents/skills/gpui-component-skill`。
- 源码结论：当前仅单 binary、无 `lib.rs`，`main.rs` 混合命令编排与终端输出；`signal/strategy/metrics/audit` 可复用。GUI 必须在进程内调用 typed application service，禁止解析 CLI stdout。先补 DTO、任务协议、DB migrations/事务/单写者、资源路径，再接 GUI。
- 产品决策：CLI 保留，新增可选 `mns-gui`；首页聚焦资产、新鲜度、今日报告、配置偏离和已成交登记，高级审计不放首页；不自动下单，不把 FGI 包装成买卖点，交易按钮只登记已完成交易。图表采用中国习惯涨红跌绿、默认 ¥。
- GPUI 用法：本地 skill 的 Entity/RenderOnce/DataTable/Dialog/后台任务原则保留；启动按当前官方 `gpui-kit` 单依赖 API，`gpui_kit::open_window` 已包装 Root，不照搬旧版手动 Root 骨架。专用 JobRunner 管理 Tokio 网络、`spawn_blocking` CPU/SQLite、进度与取消。
- 风险门：官方当前 GPUI Kit 0.9.0；`gpui-tray 0.3.0` 文档示例仍指 gpui-kit 0.6 并要求 GPUI 类型兼容，先做 macOS/Windows 窗口+托盘+后台任务+打包 spike，托盘隔离为 adapter，不预设版本组合可用。
