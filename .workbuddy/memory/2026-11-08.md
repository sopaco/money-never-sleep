## 回测与 Profile 验证体系深度评估（只读，产出 `docs/backtest-validation-review-2026-11-08.md`）

- 用 Python 独立复现 `backtest.rs::run()`，与 Rust 实跑逐项吻合（XIRR 10.69% / MaxDD 8.92% / 期末 ¥961,183 / 费用 ¥954 / 31 笔 / 3.4 次每年），后续敏感性实验均以此基线为准（脚本 `/tmp/mns_analysis.py`，临时产物）。
- **核心结论**：情绪择时在本样本无可辨识贡献。300 次信号时序置换 XIRR P5/P50/P95 = 9.90/10.51/11.07%，真实信号 10.69% 仅第 72 分位；恒定 74.5% 仓位无信号 = 10.53%/8.30%/13 笔，几乎等价且回撤更低、交易少 58%。策略与买入持有的 3pp/年差距主要来自平均 25% 现金拖累。
- **频次口径五套不一致**：用户实际 10-20 次/年；实盘信号（7天平滑+3天确认+每日决策）区间切换 19.1 次/年；回测 3 月平滑 6.1 次/年、实际成交 3.4 笔/年；单测注释 24-36 次/年、SKILL 引用 10.2-14.8 次/年。31 笔中 9 笔在注资月、仅 21/112 月有交易；3 月平滑后极端区间 112 月内仅出现 3 次。band 收窄到 2pp（12.1 笔/年）XIRR 仅 +0.16pp、费用 +126%。
- **四重数据错配**：回测 270042/510880/518880，实盘 018966/539001/007605/020341（全为场外联接）；红利腿 000015 上证红利 vs 930740 300红利低波（近1年 +2.6% vs 中证红利低波 -3.38%）；主序列止 2025-04、holdout 止 2026-07，用户 2026-07-16 入场后的纳指/黄金急跌完全缺席；回测假设 10万+每年5万共55万注资，实盘 1 万且 `cashflow.monthly=0`。
- **方法缺陷**：MaxDD 用含注资的 `total_value` 且基于月频净值（holdout 黄金月度 -24.68% vs 真实日度 -33.07%）；引擎假设月末同刻获知 FGI+净值并成交，忽略场外 QDII 赎回 T+5~T+7、T+1 确认、限购与溢价；`Costs` 混合场外申购费/赎回阶梯与场内即时到账，不对应任何真实通道；FGI 采样口径在 2020-10 从日度月末变为双周稀疏。
- **修正此前产品评审的一处外推错误**：`docs/product-review-2026-11-08.md` 把「小额多频加仓」类比为「月频定投回撤 5.44%」不成立——后者依赖外部新增资金摊薄成本，用户是从既有现金做内部再平衡，两者数学上不同。
- 外部数据经 NeoData 核实（截至 2026-11-06）：纳指100 近10年年化 19.2%、2000-2002 最大回撤 82.9%；270042 近1月 -12.95%/近1年 MaxDD -15.36%；518880 近1年 MaxDD -33.07%；007605 年化跟踪误差 1.1-1.78%。
- 优化方案按 P0（实盘标的日频数据 + 账户镜像回测 + 统一信号口径 + 分通道成本结算 + 数据新鲜度 SLA）/ P1（置换检验入 CI、日度回撤口径、熊市压力测试、Profile 三维命名、holdout≥36月、修单测断言）/ P2（交易频次预算、日报口径披露）分层，报告内附可量化验收标准。评估阶段未改动仓库源码、数据或用户配置（后续整改另记）。

## 整改落地（同日，产出 `docs/remediation-2026-11-08.md`）

- **架构决策**：不修补旧月频引擎，而是换掉主验证对象。默认 `mns backtest` = 新增 `src/audit.rs` 的日频实盘审计链路；旧 `backtest.rs` 月频代理引擎降级为 `mns backtest legacy`，输出显著警示。避免两条链路用不同信号却互相引用结论。
- **数据分层（用户追加要求：样本穿越牛熊、覆盖 2016 至今）**：实盘四只基金共同区间仅 34 个月（020341 成立于 2024-01），无法同时满足「实盘标的」与「2016 起点」，故拆两层且不混用。`live_daily.csv`（实盘四基金，2024-01-11~2026-11-06，682 行，含全收益指数 + 真实单位净值）用于账户镜像；`long_daily.csv`（539001 / H30269 价格指数 / 518880，2016-01-04~2026-11-06，2637 行）用于牛熊检验。两脚本均 point-in-time as-of 对齐（FGI 严格早于交易日、净值不晚于交易日），消除前视偏差。
- **FGI 新数据源**：`whit3rabbit/fear-greed-data` GitHub 合并存档，2011 起 3963 条日频，修掉原 2020-10 日度→双周口径断裂；2021-02 前后整数/浮点精度断点已在 meta 标注。红利腿 930740 仅 2018-12 起有数据，长周期层改用 H30269 价格指数（不含股息），与基准同口径故相对比较仍成立。
