## C1 系统上下文报告

### 系统定义

MNS（Money Never Sleeps）是一个面向个人投资者的逆向投资决策助手 CLI 工具。它解决的核心痛点是：**投资的敌人不是市场，而是人性**——恐慌时不敢买、贪婪时不愿卖。MNS 把"在恐慌中贪婪、在贪婪中恐慌"这套逆向策略数字化，通过 CNN 恐贪指数感知市场情绪，用规则代替情绪，在关键时刻给出**系统化的买卖建议**。

它不做三件事：不预测市场方向、不自动执行交易、不保证超额收益。它的定位是"决策支持"，最终买入卖出的决定权永远在用户手上。工具真正的价值在于纪律性——当大盘暴跌导致恐慌指数飙升时，它不会像人一样手足无措，而是冷静地算出"应该加仓多少钱"。

### 用户角色

MNS 是个人 CLI 工具，用户角色非常单一但使用场景分层：

| 角色 | 描述 | 主要使用场景 |
|------|------|------------|
| 个人投资者（核心） | 拥有 A股基金/美股 ETF/黄金 等资产的个人，希望系统化执行逆向投资 | 每日 `mns report` 获取操作建议；`mns update-prices` 更新价格；`mns portfolio` 查看持仓 |
| 策略研究者（进阶） | 想验证/调优逆向策略参数的用户 | `mns backtest`、`mns backtest validate` 对比策略表现、做样本外验证 |
| AI 编程代理（协作） | OpenClaw 等 AI 工具通过 SKILL 辅助用户调参 | 读取 `.ai-context/SKILL.md`、执行 `mns backtest run --config` 批量验证 |

所有角色都通过命令行接口使用系统，无图形界面、无远程服务端。

### 外部系统依赖

| 外部系统 | 交互类型 | 数据流向 | 关键性 |
|---------|---------|---------|-------|
| CNN Fear & Greed Index API | HTTP API（JSON） | 入（情绪信号） | 高——报告的核心输入，无法访问则报告降级为仅持仓建议 |
| Yahoo Finance chart v8 API | HTTP API（JSON） | 入（美股/ETF 价格） | 高——美股持仓价格来源 |
| 东方财富移动端基金 API | HTTP API（JSON） | 入（国内基金净值/估值） | 中——国内基金价格首选来源 |
| 天天基金 fundgz JSONP | HTTP API（JSONP） | 入（国内基金估值，备用） | 中——部分网络环境已不可用的降级来源 |
| 本地文件系统（~/.mns/） | 文件 | 双向（配置 + SQLite DB） | 高——全部状态持久化 |
| 本地 CSV（编译期嵌入） | include_str! | 入（回测历史数据） | 中——回测功能的数据基础，编译期固定 |

### 业务价值

- **解决的核心问题**：投资者在恐慌/贪婪极点时做出反直觉但正确的仓位决策；防止情绪化追涨杀跌
- **主要输入**：CNN 恐贪指数（实时）、资产价格（实时/手工）、用户持仓记录（手工录入买入卖出）
- **主要输出**：每日策略报告（终端 + `reports/*.txt` 落盘）、持仓/交易/市场概况表格、回测对比报告
- **决策逻辑**：目标仓位框架——由恐贪指数映射出"风险资产目标总权重"（极度恐慌 85% → 极度贪婪 35%），实际权重偏离目标超过带宽（±4pp）才动作；卖出先于买入计算，卖出现金回收计入买入预算

### 系统边界（范围内）

- 持仓、现金、交易记录的本地持久化（SQLite）
- 实时市场情绪与价格获取（CNN FGI、Yahoo、东方财富、天天基金）
- 目标仓位 + 偏离带调仓计划生成（含风险警告、逆向加仓分配）
- 每日报告渲染与落盘
- 策略历史回测（4 种引擎、趋势/情绪双锚点、样本外验证、bootstrap）
- 配置的声明式管理与合法性校验

### 系统边界（范围外）

- **不执行交易**：只给建议，不连接券商、不下单
- **不预测市场**：不做涨跌方向预测，只做情绪→仓位的规则映射
- **不管理多用户/多账户**：单用户、单数据库（`~/.mns/mns.db`）
- **无 GUI/Web 服务**：纯 CLI，本地运行
- **不保证跑赢买入持有**：README 明确披露收益低于买入持有，价值仅在风险调整后（低回撤）成立
