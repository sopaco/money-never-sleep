# 5. 边界接口

> 面向想要"对接/调用 MNS"的读者。MNS 的对外接口只有三个面：命令行（CLI）、配置文件（TOML）、外部 API 依赖。本文逐一列举。

## CLI 接口

MNS 的全部对外接口就是一个 CLI。17 个顶层命令 + 3 个子命令体系，全部由 clap derive 声明在 `src/cli.rs`。

### 核心命令详解

#### `mns init`

初始化配置文件和数据库；已存在时提示确认（除非 `--force`）。

| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `--force` / `-f` | bool | 否 | false | 跳过确认，强制覆盖已有数据（会删除旧数据库！） |

```bash
mns init
mns init --force
```

#### `mns config`

无参数查看全部配置；一个参数查看单项；两个参数修改单项（修改后自动校验合法性，校验不过不落盘）。

| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `key` | String | 否 | - | 配置项 dot-path（如 `thresholds.fear`、`rebalance.band_pp`） |
| `value` | String | 否 | - | 配置项新值 |

```bash
mns config                      # 查看全部
mns config thresholds.fear      # 查看单项
mns config rebalance.band_pp 6  # 修改：放宽偏离带以减少交易
```

#### `mns cash`

无子命令查看现金余额；`set` 覆盖设置；`add` 增加现金。

| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `set <amount>` | f64 | 视子命令 | - | 覆盖设置余额（拒绝负数） |
| `add <amount>` | f64 | 视子命令 | - | 增加余额（须为正数） |

```bash
mns cash
mns cash set 100000
mns cash add 5000
```

#### `mns add`

新增资产到持仓池。

| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `code` | String | 是 | - | 资产代码（如 QQQ、510880） |
| `name` | String | 是 | - | 资产名称（如"纳指100"） |
| `category` | String | 是 | - | 类别：`us_stocks` / `cn_stocks` / `counter_cyclical` |

```bash
mns add QQQ "纳指100" us_stocks
```

#### `mns buy` / `mns sell`

记录一次买卖。内部校验现金余额（买入）与持有量（卖出），在事务中更新持仓+现金+交易流水。

| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `code` | String | 是 | - | 资产代码 |
| `shares` | f64 | 是 | - | 份额（须为正数） |
| `price` | f64 | 是 | - | 价格（须为正数） |

```bash
mns buy QQQ 50 380.00
mns sell QQQ 20 420.00
```

#### `mns backtest`

策略回测。默认跑 5 个变体对比（趋势锚/情绪锚/旧框架/买入持有+再平衡/买入持有），同一数据与成本模型。

| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `run --config <path>` | String | 否 | 默认配置 | 用指定配置文件回测 |
| `run --compare <path1,path2>` | String | 否 | - | 对比多个配置（逗号分隔） |
| `validate --iterations <n>` | usize | 否 | 2000 | bootstrap 重采样次数 |
| `validate --block <n>` | usize | 否 | 6 | 分块长度（月） |
| `params` | - | - | - | 查看可调参数列表 |

```bash
mns backtest
mns backtest run --config my.toml
mns backtest run --compare a.toml,b.toml
mns backtest validate --iterations 5000 --block 12
mns backtest params
```

#### `mns update-prices`

遍历持仓，按代码特征自动选择数据源（6 位数字→天天基金/东财；字母→Yahoo）批量更新价格，失败资产跳过不中断。

```bash
mns update-prices
```

#### `mns analyze`

个股基础分析（当前报价、涨跌）。走 Yahoo Finance v8。

| 参数 | 类型 | 是否必须 | 默认值 | 说明 |
|------|------|---------|-------|------|
| `symbol` | String | 是 | - | 股票代码（如 AAPL、^GSPC） |

```bash
mns analyze AAPL
```

## 配置结构

配置文件位于 `~/.mns/config.toml`。核心结构（详见 `src/config.rs`）：

| 配置节 | 关键项 | 默认值 | 含义解读 |
|-------|--------|-------|---------|
| `target_weight` | `extreme_fear/fear/neutral/greed/extreme_greed` | 85/75/60/45/35 (%) | **策略灵魂**：各情绪区间下风险资产目标权重。必须随情绪升高单调不增（逆向策略约束），校验失败拒绝加载 |
| `rebalance` | `band_pp` | 4.0 (pp) | 偏离带：实际权重偏离目标 ≤带宽 则不动作。带宽越大交易越少，是控制交易频率的主要旋钮 |
| `rebalance` | `min_trade_amount` | 500 (¥) | 最小交易金额，避免无意义碎单 |
| `rebalance` | `min_holding_days_for_sell` | 30 (天) | 卖出最短持有期，规避国内基金惩罚性赎回费窗口 |
| `costs` | `buy_fee_pct` / `sell_fee_pct` | 0.12 / 0.05 (%) | 买卖成本，回测与决策共用 |
| `costs` | `cash_annual_yield` | 2.0 (%) | 闲置现金货币基金年化收益（回测计息） |
| `costs` | `redemption_tiers` | [(7,1.5),(30,0.75),(365,0.5),(730,0.25)] | 阶梯赎回费：按持有天数取档 |
| `thresholds` | `extreme_fear/fear/neutral/greed` | 30/45/55/70 | 情绪区间分界，必须严格单调递增 |
| `allocation` | `us_stocks/cn_stocks/counter_cyclical` | 55/25/20 (%) | 三腿资产内部比例，之和必须=100% |
| `settings` | `annualized_target_high/low` | 15.0/10.0 (%) | 止盈阈值（旧框架卖出逻辑） |
| `api` | `fear_greed_url` | CNN graphdata URL | 恐贪指数 API 端点 |

## 集成建议

- **CI/定时触发**：`mns report` 是幂等的每日建议生成器，可配 cron/LaunchAgent 每日收盘后自动执行，输出 `reports/{date}.txt` 存档，形成自己的"决策日志"。
- **数据管线**：先 `mns update-prices` 再 `mns report`，保证价格新鲜度；`record_price` 逐日累积价格历史，累计 12 个月后可切换到趋势锚信号（src/report.rs:282-291 有说明）。
- **参数实验**：用 `mns backtest run --compare a.toml,b.toml` 做 A/B——所有配置走同一数据与成本模型，对比公平。
- **AI 协作**：OpenClaw 等工具通过 `.ai-context/SKILL.md` 与 `mns backtest params` 输出的参数清单安全调参，AI 修改参数有 `config.validate()` 兜底不会写出非法配置。
- **备份**：整个系统状态就是 `~/.mns/` 两个文件（config.toml + mns.db），备份即复制。
