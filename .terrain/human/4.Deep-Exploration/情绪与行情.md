# 情绪与行情

> 源码：`src/sentiment.rs` + `src/quote.rs` + `src/market.rs`

## 模块职责

情绪与行情模块是 MNS 的"情报科"——系统与外界的唯一通道，负责三件事：拉取 CNN 恐贪指数（策略的信号输入）、获取持仓资产的实时价格、拉取全球市场指数。没有它，策略模块就"无米下锅"。

模块最重要的设计哲学是**多源冗余 + 优雅降级**：免费金融 API 随时可能反爬、限流甚至下线，所以每个数据需求都准备了主源和备用源，单个失败不拖垮整体。

## 核心功能

| 功能 | 位置 | 说明 |
|------|------|------|
| CNN 恐贪指数 | src/sentiment.rs:57 | 浏览器 UA/Referer 头规避反爬，3 次重试，418 明确提示 |
| 智能路由价格 | src/quote.rs:178 | 6 位纯数字 → 天天基金；字母 → Yahoo |
| 批量价格更新 | src/quote.rs:197 | 顺序遍历持仓，失败跳过不中断 |
| 全球指数概览 | src/market.rs:45 | 9 个指数固定清单，失败汇总成错误表 |
| 个股报价分析 | src/quote.rs:245 | Yahoo v8 chart API 解析，供 `mns analyze` |

### 恐贪指数获取

`fetch_fear_greed_data`（src/sentiment.rs:57）请求带浏览器 UA、`Accept-Language`、`Referer` 头（src/sentiment.rs:81-88）规避反爬，内置 3 次重试（间隔 500ms），对 418 反爬拦截给出明确中文提示（src/sentiment.rs:92-98）。解析时从 JSON 文本提取历史值（`extract_historical_value`，src/sentiment.rs:139），供报告做环比/同比。

### 智能路由价格获取

`fetch_price`（src/quote.rs:178）按代码特征选数据源：

```mermaid
flowchart TD
    A["资产代码"] --> B{"6位纯数字?"}
    B -->|是| C["fetch_from_tiantian<br/>东财移动端优先"]
    C -->|东财失败| D["天天基金 JSONP 兜底"]
    B -->|否| E["fetch_from_yahoo"]
    D --> F["价格 Option<f64>"]
    E --> F
    F --> G["update_all_prices 批量更新<br/>失败跳过不中断"]
```

降级链是核心模式（src/quote.rs:124-129）：`fetch_from_tiantian` 先试东财移动端再试 JSONP——上游失效自动滑到下游，用户无感知。

## 跨模块协作

| 交互模块 | 方向 | 说明 |
|---------|------|------|
| 配置系统 | 依赖 | 恐贪指数 URL 来自 `api.fear_greed_url`（src/config.rs:217-220） |
| 数据模型 | 依赖 | `Position`（批量更新遍历持仓） |
| CLI 与命令分发 | 被依赖 | `cmd_report` / `cmd_update_prices` / `cmd_market` 调用 |

**协作场景**：每日报告中本模块是第一步——`cmd_report` 调用 `sentiment::fetch_fear_greed_data` 拿到情绪信号（src/main.rs:356），后续所有决策都建立在这个输入上。价格批量更新中本模块是执行者——`quote::update_all_prices` 产出 `Vec<PriceUpdate>`，命令层写回数据库（src/main.rs:783-799）。

## 扩展点

- **新增数据源**：新增 `fetch_from_xxx` 函数（与 `fetch_from_eastmoney_mobile` 同签名 `(code) -> Result<Option<f64>>`），在 `fetch_price` 或 `fetch_from_tiantian` 的降级链中插入即可（src/quote.rs:124-129 展示模式）。
- **新增指数**：在 `MARKET_INDICES` 常量加一行（src/market.rs:19-29），自动纳入 `mns market` 与 `mns market-indices`。
- **API 端点可配**：恐贪指数 URL 由配置 `api.fear_greed_url` 控制，无需改代码即可切换镜像/代理。

## 性能考量

网络 IO 是系统唯一的外部延迟来源。设计选择是**顺序请求而非并发**（src/quote.rs:197-235）——放弃并发速度，换来了对免费 API 的友好与实现简单。请求均设超时（连接 5-10s、请求 10-15s），避免单次挂死拖垮命令。重试策略只用于最关键的恐贪指数（src/sentiment.rs:62-77），价格批量更新不重试（逐个失败逐个跳过）——价格明天还会再拉，而报告需要当下就要结果。

## 实现亮点

- **降级链设计**（src/quote.rs:124-129）：东财移动端失效自动滑到天天基金 JSONP，用户无感知。
- **反爬对抗的工程细节**：浏览器 UA + `Accept-Language` + `Referer`（src/sentiment.rs:81-88, src/quote.rs:138-150）——免费 API 需要"像浏览器"才能拿到数据。
- **优雅失败**：`mns market` 中恐贪指数获取失败只打警告不报错退出（src/main.rs:862-870）——市场概况命令核心是指数表，情绪失败不应让整个命令失败。
