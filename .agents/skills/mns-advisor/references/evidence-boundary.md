# 证据边界与禁用话术

本文件是输出结论前的最后一道核对。所有数字来自 `docs/remediation-2026-11-08.md`、`docs/hs300-experiment-2026-11-08.md`、`docs/guardrail-experiment-2026-11-08.md`（2026-11-08）。

## 已证伪 / 已确立的事实

| 结论 | 证据 |
|---|---|
| 情绪信号无显著择时贡献 | 三资产 10.8 年真实信号置换检验第 **63** 分位，未过 80 分位门槛 |
| 换到 A 股也不成立 | 沪深300 上 FGI 第 **44** 分位；本地 200 日均线逆向信号第 **61** 分位；FGI 与未来 20 日收益相关系数 0.0562，55–75 贪婪档未来收益反而最高 |
| 常数仓位常等价或更优 | 70–75% 常数仓位在多数对照中收益相当或更好，交易显著更少 |
| 「过热之后更差」未通过检验 | 四种过热定义的 20 日收益差 -0.10~-1.03pp，年块 bootstrap 95% CI 全部跨 0；尾部概率差 CI [-10.2, +27.8]pp |
| 自动否决买入不是稳健规律 | 三资产池 -102 ~ -460 元、沪深300 +294 ~ +1,180 元，跨资产反向且阈值非单调 |
| 真正昂贵的是计划外大额追加 | 三资产池约 -4,914 元，而护栏在该场景反而 -388 元；护栏不改变 MaxDD |
| 严格执行会超交易预算 | 32.3 次/年 vs 预算 10–20 次；实际流水 19.4 次/年；QDII 限购阻断 7 次 |
| 账户镜像 | 期末净值差 ¥135.45（严格 ¥9,878.06 vs 实际 ¥9,742.61） |

结论方向：**可验证的价值是纪律性仓位约束、执行可行性与对账，不是择时 alpha。**

## 口径边界

- 三层数据不可混用：`live_daily.csv`（实盘四基金，2024-01 起）用于账户镜像；`long_daily.csv`（2016 起，三腿**代理**标的，红利腿为价格指数、黄金腿为场内 ETF）只用于稳健性比较；`hs300_daily.csv` 只用于单资产对照。
- 实盘层共同区间仅 34 个月、FGI 可验证段约 240 个交易日，结论强度有限。
- 2000–2002 与 2008 型多年熊市**未经检验**；不要用合成数据或「应该也能扛住」填空。
- `backtest legacy` / `validate` 是 2016–2025 月频代理、3 月平滑、月末成交、10 万起步 + 年注资 5 万，与真实账户不是同一策略。
- 护栏实验中的行为基线是人为行为模型，不是真实流水；「护栏的价值」取决于人本来会犯多大的错，属反事实，行情数据测不出。
- 描述性统计（FGI≥75 后 60 日下跌概率 33.7% vs 全样本 25.9%、5% 左尾 -7.70%）仅用于理解风险，**未通过显著性检验**。

## 禁用话术与替代表述

| 禁用 | 替代 |
|---|---|
| 「现在是买点 / 卖点」 | 「本次交易由 A 现金流事件授权，金额按缺口分配」 |
| 「恐慌了，该加仓」 | 「决策分数处于恐慌区，目标仓位刻度为 X%；是否动手取决于新钱或偏离」 |
| 「恐贪高位，先别买 / 建议减仓」 | 「处于过热区，建议延迟 1 个交易日并写明理由；不阻断交易」 |
| 「这个策略能跑赢 / 回撤更小」 | 「样本内风险调整后优势未外推到样本外；置换检验未过门槛」 |
| 「历史上涨概率 X%，所以…」 | 「描述性统计未通过显著性检验，不作为依据」 |
| 「预计年化 X%」 | 不写；只写可核对的事实与金额 |
| 「帮你下单 / 已买入」 | 「待你确认成交后，用 `mns buy ...` 登记」 |
| 「长期看没问题」 | 「2000–2002 / 2008 型多年熊市未经检验」 |

## 输出前的自检

1. 是否把 FGI 或新闻写成了买卖理由？
2. 是否出现了收益预测、目标价、胜率？
3. 是否把长周期代理回测数字用在实盘语境？
4. 是否为了给出「有用」的结论而制造了一笔交易？
5. 每条数字是否标注了来源（MNS 计算 / 联网事实 + 日期 / 用户陈述 / 推断）？
6. 是否明确写出「本周是否操作」以及不动作的原因？
7. 是否说明本框架不构成投资建议、不改变最终决策权？

任一项不过关，重写决策卡后再输出。
